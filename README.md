# Disk Cleaner

Приложение для macOS на Go + [Fyne](https://fyne.io). Находит то, что занимает место и может быть удалено без потерь, объясняет, что это и почему это можно удалить, и перед удалением показывает точный список команд.

| Раздел | Что находит |
|---|---|
| Worktrees | `node_modules`, `Pods`, `build`… в git worktree (только то, что git игнорирует) |
| Projects | то же в основных репозиториях: неактивные (без коммитов 30+ дней) и активные отдельно; плюс «Оставленные сборки» — `.xcarchive`, `.ipa`, `.apk`, `.aab`, `.dmg`, `.app`, которые лежат рядом с кодом и git их не отслеживает (так же в Worktrees) |
| Xcode | DerivedData, архивы, символы устройств, кэш документации, превью SwiftUI |
| Simulators | версии iOS/watchOS/tvOS/visionOS для симуляторов, сами симуляторы, кэш dyld |
| Android | эмуляторы (AVD), системные образы, версии NDK, исходники SDK |
| Docker | контейнеры, образы, тома, кэш сборки |
| Developer tools | редакторы, IDE и AI-инструменты (Cursor, VS Code, Claude Code, Codex, JetBrains, Android Studio, Windsurf, Antigravity, Zed, Gemini CLI… — таблица в `providers/devtools/tools.go`): остатки удалённых программ, старые версии (CLI, расширения, папки прошлых версий IDE), кэши и временные файлы, скачанные среды; данные Claude и история Claude Code — только для информации |
| AI models | модели LM Studio и Ollama, кэш Hugging Face, модели приложений (Lingary, Argos Translate), хранилище llmstore (только показ) |
| Package caches | npm и npx, Yarn, CocoaPods, Gradle (с архивами скачанных JDK), uv, pip, Homebrew, Go, SwiftPM, браузеры для тестов, Electron, Expo, инструменты JS (с Prisma и Corepack), pre-commit, NuGet, байт-код Python |
| Downloads | установщики (`.dmg`, `.pkg`), сборки (`.aab`, `.apk`, `.ipa`, `.xcarchive`, `.app`), архивы (`.zip`, `.xip`, `.tar.gz`…) в «Загрузках». Файлы переносятся в Корзину, а не удаляются; подключённый `.dmg` выбрать нельзя |
| App caches & logs | `~/Library/Caches` приложений (кроме системных Apple и Claude), остатки обновлений, `~/Library/Logs` |

## Команды

```bash
go run .                      # запустить из исходников
go test ./...                 # все тесты
./scripts/build.sh --install  # собрать и установить в /Applications (копия в dist/ не остаётся)
./scripts/build.sh            # только собрать dist/Disk Cleaner.app — Spotlight покажет её как вторую копию
go test -tags screenshots -run TestScreenshots ./internal/ui/ -args -lang=ru -dark   # снимки экранов в screenshots/
```

`fyne` ставится так: `go install fyne.io/tools/cmd/fyne@latest` (окажется в `~/go/bin`).

## Оформление

Как в приложениях Apple: боковая панель с цветными значками разделов (как в Системных настройках), полоса заполнения диска (как в «Хранилище»), сгруппированные плашки, метки Safe/Caution, синие ссылки «Select All» и главная синяя кнопка. Светлый и тёмный вид: по умолчанию как в macOS, а кнопкой с луной/солнцем в шапке или в Settings › Appearance можно выбрать всегда светлый или всегда тёмный.

Тема — `internal/ui/theme.go`: системные цвета macOS и шрифт San Francisco. Шрифт берётся из системы этого Mac (`/Library/Fonts/SF-Pro-Text-*.otf` или `/System/Library/Fonts/SFNS.ttf`), в программу он не вшивается — лицензия Apple этого не разрешает. Если шрифта нет, используется шрифт Fyne.

Значок и цвет раздела провайдер отдаёт через необязательный интерфейс `core.Look` (файлы `look.go` и `icon.svg` в папке провайдера).

## Что программа не удалит никогда

- Запущенное (контейнер, симулятор, эмулятор, демон Gradle, процесс из worktree) — галочку не поставить, рядом написано, кем занято.
- Записи симуляторов, у которых общий образ на диске, самую новую версию каждой платформы и симуляторы с «потерявшейся» версией системы.
- В worktree — всё, что git отслеживает.
- Домашнюю папку, её папки первого уровня (`~/Projects`, `~/Library`…) и данные других приложений (`~/Library/Application Support`, `Preferences`, `Keychains`, `Mail`…): исполнитель откажется, даже если провайдер ошибётся.
- С паролем администратора — только удаление путей внутри `/Library/Developer/CoreSimulator/Caches`. Команды с правами администратора запрещены.

Режим «Dry run» в настройках показывает план, ничего не удаляя.

## Поиск и выбор

- **Поиск по всем разделам** — поле вверху боковой панели (⌘F). Справа появятся результаты, сгруппированные по разделам; слева у каждого раздела — сколько в нём найдено.
- **Поиск в разделе** — поле над списком открытого раздела.
- Запрос делится на слова, каждое должно найтись в имени, пути или названии категории: `lingary node` найдёт `node_modules` из worktree Lingary.
- **«Выбрать все»** выбирает то, что сейчас видно (с поиском — только найденное) и что можно выбрать; нажатие ещё раз снимает отметки. Галочка в заголовке категории выбирает всю категорию.
- По умолчанию всё компактно: объект — одна строка (имя, путь, метка «Running»/«In use»/«Protected», размер). Клик по заголовку категории раскрывает объяснения, полные пути и причины.

## Архитектура

```
main.go                      точка сборки: список провайдеров
internal/
  core/                      ядро: Item, Category, Selection, Plan, Provider, Executor (интерфейсы)
  diskutil/                  свободное место, размер папок
  shell/                     запуск программ без оболочки
  executor/                  настоящее удаление + проверки безопасности
  i18n/                      переводы, выбор языка
  settings/                  настройки (язык, папки worktree, dry run)
  ui/                        окно Fyne; знает только core
  providers/
    kit/                     общие кирпичики для провайдеров
    providertest/            общие проверки для тестов провайдеров
    gitscan/                 поиск git-репозиториев и игнорируемых папок (для worktrees и projects)
    worktrees/ projects/ xcode/ simulators/ android/ docker/ models/ devtools/ packagecaches/ appcaches/
```

Зависимости направлены к `core`: `core` не импортирует ничего из проекта, провайдеры не импортируют друг друга, `ui` не знает ни одного провайдера.

### Как добавить провайдер

1. Папка `internal/providers/<имя>/` с типом, у которого есть методы `ID`, `Categories`, `Scan`, `Plan`, `Translations` (см. `internal/core/provider.go`).
2. По желанию — `icon.svg` (белый рисунок 24×24) и `look.go` с цветом плашки.
3. `translations/en.json` и `ru.json`: `<имя>.name` и для каждой категории `title`, `what`, `why`, `after`.
4. Тест с `providertest.CheckTranslations` — он проверит, что ни один текст не забыт.
5. Одна строка в `main.go`.

Убрать провайдер — удалить его папку и строку в `main.go`.
